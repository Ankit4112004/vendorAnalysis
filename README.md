# Vendor Analysis

This repository contains tools, scripts, and reports for analyzing vendor performance. 

## Project Contents

- **Notebooks:**
  - `Exploratory Data Analysis.ipynb` - Initial data exploration.
  - `Vendor Performance Analysis.ipynb` - In-depth analysis of vendor metrics.
- **Reports & Dashboards:**
  - `Vendor Performance Report.pdf` - PDF summary of vendor performance.
  - `vendor_performance.pbix` - Power BI dashboard for interactive vendor analytics.
- **Scripts:**
  - `ingestion_db.py` - Script for database ingestion.
  - `get_vendor_summary.py` - Script to generate vendor summaries.
- **Data:**
  - `vendor_sales_summary.csv` - Summary dataset containing vendor sales information.
